# Shakib | Modern Developer Portfolio

A sleek, editorial dark-mode portfolio for **Shakib (Sihab Sharar)**, Full-stack Developer in Progress.

## Features

- **Next.js 15 App Router** & **TypeScript**
- **Tailwind CSS** with bespoke editorial dark design system (`#0B0D0C`, `#141715`, `#F4F5F0`, `#A0A69F`, `#C5F467`)
- **Real Verified Project Showcases**: Featured case study of **Bazar Dor** with genuine UI captures
- **Verified Social Links**: Direct working connections with accessible labels
- **Modular Data Architecture**: Centralized data configuration for projects, skills, resources, and blog posts
- **Fully Responsive**: Mobile-first architecture with smooth micro-interactions

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Open in browser
http://localhost:3000
```
